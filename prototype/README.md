# Legacy UI prototype

Thư mục này giữ giao diện HTML/CSS/JS cũ làm reference UI/UX. Nó chứa dữ liệu mock được hard-code và không phải frontend production.

Mở `index.html` trực tiếp bằng trình duyệt để xem prototype. `style.css` chứa style và `script.js` chứa giao diện/điều hướng; file JavaScript là bundle được biên dịch từ React/TSX.

Frontend production sẽ được rebuild bằng React + TypeScript dựa trên reference này, nhưng không sao chép kiến trúc cũ. Không phát triển feature mới trực tiếp trong thư mục này.
